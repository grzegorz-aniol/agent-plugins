name: double-check
description: Task implementation double-check. Review all changes made in a session to find any mistakes or inconsistencies. Invoke when you fully finish implementation and fix all tests/bugs.
user-invocable: true
---

Review all changes you made and check for:

- mistakes or bugs
- serious inconsistencies
- overly complicated code that could be simplified
- functions, classes, or files that are too large and where independent logic could be extracted into a new function, class, or module
- violations of YAGNI, KISS, and DRY principles
